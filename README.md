# EasyCargoTools

Suite móvil Android para cálculo y optimización de carga y finanzas logísticas.

## Herramientas
- **Carga 3D**: Visualizador WebGL Three.js con empaque tridimensional, presets (20', 40', pallets US/Euro) y modos multi-bulto.
- **Volumen**: Cálculo de rendimiento por pie cúbico ($/ft³), litros y comparador dual.
- **Divisas**: Arbitraje cambiario oficial BCV vs paralelo con cálculo de ahorro real y brecha.
- **Aduana**: Base imponible CIF, aranceles ad valorem (37%, 52%, 72%) y desglose logístico.
- **Finanzas**: Simulador de préstamos y cuotas APR (amortizado mensual vs bullet).
